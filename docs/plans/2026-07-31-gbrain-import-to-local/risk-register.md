## Decisions
- **Category B canonical storage scope** — Resolved (assessment): one canonical document copy under `DocumentAvailabilityScope.User` (`documents/{tenant}/user/{Guid.Empty}/{user}/{fingerprint}`) with channel-authorized retrieval rather than per-channel duplication. Converged from grok/gemini/chatgpt reviews; eliminates 3× storage/chunk/embedding cost and makes dedupe content-addressable at write time (`ExistsAsync`).
- **Merge/dedupe strategy** — Resolved (assessment): Option 3-lite — fingerprint-grouped dedupe (last slug segment) with deterministic representative ordering, provenance internal only (tool payload shape frozen; debug log of candidate set; additive provenance field deferred), implemented in `GBrainDocumentStoreClient` so both tools share one tested path. See R13.
- **Category B collision policy** — Data-gated: dry run must report the same-fingerprint collision count. Zero → fail-hard default stands. Non-trivial re-upload variants (byte-identical, different metadata) → approved deterministic merge rule (newest `updated_at` wins, losers in manifest as `collision_strategy=merged`). Never suffix fingerprints.
- **`page_aliases` (94 rows)** — Resolved (2026-07-31): imported as-is and alias strings rewritten to the new slug space by `rewrite-pages.sql`; validation `alias orphans 0`.
- **`tags` (1,942 rows)** — Resolved (2026-07-31): imported as-is (FK `page_id` only, tag values untouched); validation `tag orphans 0`.

## Post-implementation Addendum (2026-07-31)
- Real-mode restore initially failed twice: (1) `docker cp` into a missing container dir; (2) local `pages` column ORDER differs from the remote dump's trailing 8 columns (`restore-real.sql` initially copied positionally → `\copy imp_pages` type errors). Fixed by defining the temp `pages` table in remote order and mapping INSERTs by column NAME; other tables matched.
- The gbrain container's `~/.gbrain/config.json` still pointed at `gbrain_import_staging` from the staging session → the real-mode re-embed plan silently showed `chunks_to_embed: 0` (`skipped_no_work`) against the fully-embedded staging DB. Script now pins `GBRAIN_DATABASE_URL` to `gbrain` in real mode; re-embed then completed 2,993/2,993.
- Pre-existing-collision guard confirmed: any remote slug colliding with a live local slug fails the restore INSERT hard (atomic), so no partial state is possible.
